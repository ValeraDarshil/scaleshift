✅ ZERO DEPENDENCIES — No install needed!

   Just open the file and it works instantly.

================================================
  HOW TO RUN (3 ways)
================================================

METHOD 1 — Simplest (Double Click)
------------------------------------
  1. Extract the ZIP folder
  2. Open the "scaleshift" folder
  3. Double-click "index.html"
  4. It opens in your browser — DONE! 🎉

METHOD 2 — VS Code Live Server (Recommended)
----------------------------------------------
  1. Install VS Code: https://code.visualstudio.com
  2. Install the "Live Server" extension
     (Ctrl+Shift+X → search "Live Server" → Install)
  3. Open the scaleshift folder in VS Code
  4. Right-click index.html → "Open with Live Server"
  5. Site opens at http://127.0.0.1:5500

METHOD 3 — Python (if you have Python installed)
--------------------------------------------------
  1. Open Terminal / Command Prompt
  2. cd into the scaleshift folder
     e.g.  cd C:\Users\YourName\Desktop\scaleshift
  3. Run:  python -m http.server 3000
  4. Open browser → http://localhost:3000

================================================
  DEPLOY / GO LIVE
================================================

  Option A — Netlify (FREE, easiest):
    1. Go to netlify.com → Sign up
    2. Drag & drop the scaleshift FOLDER onto Netlify
    3. Your site is live in 30 seconds! ✅

  Option B — GitHub Pages (FREE):
    1. Create GitHub account
    2. New repo → upload index.html
    3. Settings → Pages → Deploy from main branch
    4. Live at: yourusername.github.io/scaleshift

  Option C — Your own hosting (cPanel):
    Upload index.html to public_html folder via File Manager
